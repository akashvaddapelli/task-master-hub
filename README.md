TASK MANAGEMENT SYSTEM:
Task Management System is a full-stack web application designed to help users efficiently create, organize, and track their tasks. The system allows users to manage daily activities by setting priorities, deadlines, and tracking progress through different status stages such as To-Do, In Progress, and Completed.

It includes secure user authentication, role-based access control, and a responsive interface to ensure smooth task handling across devices. The application is built using modern web technologies with a RESTful API architecture, enabling seamless communication between frontend and backend while ensuring data security and scalability.

This project demonstrates strong full-stack development skills, including UI design, API development, database integration, authentication, and deployment.
